# Михаил — интерфейс и объяснение

> Карточка второй версии. Одноимённый файл в `../../v1/assignments/` — архив первой: 65 закрытых задач, планом работ не является.

Каталог один: **`frontend/`** — React и TypeScript.

`ui/` и `llm/` — это Python: генерация web-данных из артефакта и слой интерпретируемости. Они за интегратором (`savely.md`). Если задаче нужны данные, которых фронт не получает, — не лезешь в `ui/` сам, а говоришь, какое поле нужно в бандле.

Интерфейс — прямой источник баллов, а не витрина. Организаторы отдельно назвали антипаттерн: «не должен быть набор исключительно некоторых элементов интерфейса… и в итоге кнопочка, которая позволяет скачать расписание».

## Граница пакета

Ты работаешь **только с тем, что уже лежит в `frontend/public/data`**. Фронт ничего не вычисляет и не генерирует данные для себя: величины приходят готовыми, форма бандла задана схемой `RunArtifact`. Нужна новая величина — это задача для `ui/`, и она заводится отдельно, а не правится по дороге.

## Правила пакета, которые не обсуждаются

- **Интерфейс ничего не вычисляет.** Все величины приходят готовыми из артефакта. Собственный расчёт ЧДД, обводнённости или компенсации — это вторая реализация Методики, и она разойдётся с первой.
- **Оси берутся из данных.** Литералы `225`, `224`, `103`, `371` в коде фронта запрещены.
- **`magic-mcp` только для служебного:** табы, тултипы, поповеры, ползунки, командная палитра. Карта, граф, хронокарта и любой график пишутся вручную на SVG или canvas — библиотека натренирована на лендингах, и сгенерированный ею основной экран сделает продукт неотличимым от типового AI-дашборда.
- **Запрещено:** градиенты, свечения, стеклянные панели, bento-сетки, скругления больше 4 пикселей, тени, hover-анимации со смещением, анимации без смысловой нагрузки.
- **Каждая анимация несёт величину:** скорость частицы — измеренный лаг, толщина ребра — λ, размер точки — дебит. Не кодирует число — удаляется.

## Тесты фронта

Только на Node 22.11.0. Начиная с Node 24 в рантайме появился собственный глобальный `localStorage`, который перекрывает jsdom и валит все компонентные тесты:

```bash
cd frontend && npx --yes node@22.11.0 node_modules/vitest/vitest.mjs run
```
