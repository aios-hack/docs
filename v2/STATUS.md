# Статус — единственное место, где живёт прогресс

Ни карточки задач, ни персональные файлы его не дублируют: там задача описана и задана её приёмка, а сделана она или нет — только здесь. Две копии статуса разъедутся в первый же день.

Значения ровно четыре:

| Значение | Когда ставится |
|---|---|
| пусто | не начата |
| `в работе` | сессия открыта, ставит тот, кто её открыл |
| `заблокировано` | нельзя сделать по внешней причине; причина указывается тут же |
| `готово ДД.ММ · <коммит>` | приёмка выполнена **зелёным тестом**, коммит с ней указан |

**`готово` без зелёного теста не ставится.** Не «я закончил», не «вроде работает». Приёмка каждой задачи написана в её карточке — это и есть содержание теста.
