# Статус — единственное место, где живёт прогресс

Ни карточки задач, ни персональные файлы его не дублируют: там задача описана и задана её приёмка, а сделана она или нет — только здесь. Две копии статуса разъедутся в первый же день. Что за задача и как устроено решение — не здесь: `../README.md` указывает, где смотреть.

Значения ровно четыре:

| Значение | Когда ставится |
|---|---|
| пусто | не начата |
| `в работе` | сессия открыта, ставит тот, кто её открыл |
| `заблокировано` | нельзя сделать по внешней причине; причина указывается тут же |
| `готово ДД.ММ · <коммит>` | приёмка выполнена **зелёным тестом**, коммит с ней указан |

**`готово` без зелёного теста не ставится.** Не «я закончил», не «вроде работает». Приёмка каждой задачи написана в её карточке — это и есть содержание теста.

В ячейке — только значение и, если есть находка, ссылка на неё. Замеры, гипотезы, числа и причины — не сюда, а в `findings/<дата>-<слаг>.md`: что измерено, чем измерено, число, вывод, что дальше. Дата и автор находки — из git, в тексте файла не дублируются.
