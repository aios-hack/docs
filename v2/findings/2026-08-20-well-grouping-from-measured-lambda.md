# Нарезка участков из измеренной λ

Вне очередей. Не назначено.

**Что измерено.** Число групп скважин (`Groups = f(λ)`), которое даёт измеренная λ при разных порогах слияния.

**Чем измерено.** Кластеризация по матрице λ из [замера на настоящих прогонах](2026-08-20-lambda-window-measurement.md) при разных порогах.

**Число.** Порог слияния 0.5 даёт одну группу на весь фонд, 0.7 — три, 0.9 — двадцать одну.

**Вывод.** Данные появились, решение о пороге не принято. `Groups = f(λ)` объявлен гипотезой до измерения (`../../context/07_concept.md` §6, задача 61 первой версии), теперь у него есть на чём решаться — выбирать молча нельзя.

**Что дальше.** Не назначено.
