# docker build не проходит

Вне очередей. Не назначено. Каталог `frontend/` — владелец Михаил.

**Что измерено.** Прохождение `docker build` на чистом дереве.

**Чем измерено.** Сборка стадии фронта: `npm run build` = `tsc --noEmit && vite build`.

**Число.** Падение `TS2307`: `frontend/src/app/DemoMode/frames.test.ts` импортирует `../../../public/data/demo-script.json`, а `frontend/public/data/` исключён `.dockerignore`.

**Вывод.** `tsc` типизирует и тесты, поэтому отсутствующий в образе файл данных роняет сборку до python-стадии. Дефект давний — воспроизводится и до переноса в `backend/`.

**Что дальше.** Требование сдачи «Docker-образ или материалы для сборки» закрыто только материалами. Найдено 22.08.
