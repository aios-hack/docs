# v2 — текущая работа

Рабочая область второй версии. Всё, что делается сейчас, лежит здесь; всё, что закрыто, — в `../v1/`; предметная база знаний — в `../context/`.

## Куда смотреть

| Путь | Что там |
|---|---|
| `STATUS.md` | **Единственное место, где живёт прогресс.** Все очереди, все статусы. В карточках задач статуса нет |
| `tasks/integration.md` | Очередь **G1–G7** — склейка: от «компоненты написаны» до «есть что сдавать» |
| `tasks/frontend.md` | Очередь **F1–F16** — интерфейс: база и слой отличия от других команд |
| `audit/frontend.md` | Разбор текущего интерфейса по коду, находки A1–D3. Отвечает на «почему эта задача существует» |
| `assignments/` | Четыре карточки по именам: у кого какая очередь, какие каталоги, чего не трогать |

## Как работать

1. Человек открывает **свою** карточку в `assignments/` — там его задачи и границы.
2. Агент запускается в репозитории `aios`, читает его `CLAUDE.md`, дальше идёт по промту из карточки.
3. Одна сессия — одна задача. Приёмка написана в карточке задачи и не придумывается на ходу.
4. Закрыл — правит строку в `STATUS.md`, отдельным коммитом в `docs`.

## Правила этого каталога

- Записывается **только установленное**: факты, замеры, подтверждённые решения. Идеи и рассуждения остаются в чате.
- Числа проверяются по коду и данным, а не переписываются из соседних файлов.
- Статус не дублируется: он только в `STATUS.md`.
- При противоречии с `../context/07_concept.md` первичен `07_concept.md`, пока изменение не внесено туда журналом §9.
