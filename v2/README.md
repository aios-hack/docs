# v2 — рабочий контекст обсуждений

Каталог для контекста, который рождается в обсуждениях и должен пережить сессию: разборы, замеры, принятые развилки, состояние работ второго этапа.

Правила те же, что у остального репозитория документации (`../CLAUDE.md`):

- записывается только установленное — факты, замеры, подтверждённые решения; идеи и рассуждения остаются в чате;
- числа проверяются по коду и данным, а не переписываются из соседних файлов;
- статус задач здесь не дублируется: он живёт только в `../assignments/order.md`;
- при противоречии с `../context/07_concept.md` первичен `07_concept.md`, пока изменение не внесено туда журналом §9.

Один файл — одна тема, имя в формате `NN_тема.md`.

## Содержание

| Файл | О чём |
|---|---|
| `01_frontend_audit.md` | Разбор текущего интерфейса по коду: находки A1–D3 с привязкой к файлам и требованиям организаторов |
| `02_frontend_tasks.md` | Очередь задач F1–F10 с приёмкой, общими правилами пакета и промтом для запуска сессии |
