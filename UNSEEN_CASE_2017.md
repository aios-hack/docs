## Воспроизведение аудита

Скрипт `scripts/audit_unseen_run.py` не обучает модель и не запускает OPM.
Первая фаза проверяет отсутствие точного совпадения с обучением и замораживает
прогноз; она откажется перезаписывать прогноз или запускаться после OPM.
Вторая фаза читает сохранённый отклик симулятора и считает ошибки по годам.

```bash
python scripts/audit_unseen_run.py --run-dir out/web-runs/<новый-прогон>
# Затем кнопка «Проверить план в OPM» в интерфейсе.
python scripts/audit_unseen_run.py \
  --run-dir out/web-runs/web-20260906-180829-e0cbc79a --report \
  --reference-run-dir out/web-runs/web-20260906-173732-e33316c9
```

Для фазы заморозки нужны те же production-артефакты и `AIOS_DOCS_ROOT`,
что и для приложения. Артефакты эксперимента находятся внутри каталога
прогона: `unseen-protocol.json`, `prediction/response.json`, `observation/`,
`unseen-result.json` (создаётся после завершения OPM).

## Что показало сравнение эффекта

По отношению к предыдущему подтверждённому плану:

- Прогнозируемое изменение ЧДД: **−240 749 руб.**
- Изменение ЧДД по OPM: **−11 121 249 руб.**
- Ошибка оценки изменения: **10 880 500 руб.**, или **97,84%** от модуля
  фактического изменения.
- По OPM за 2017 год добыто на 10 032,56 т нефти и 34 164,94 м³ жидкости меньше.

Следовательно, малая ошибка полного ЧДД маскирует слабую оценку небольшого
изменения результата. Этот тест не подтверждает точность ранжирования близких
по ЧДД планов. Метрики эффекта и ошибок по годам необходимо оценивать отдельно.

Обнаружена и проблема планировщика: максимальный среднемесячный суточный
отбор **предыдущего** плана был 1 411,69 м³/сут, то есть уже ниже нового лимита.
Резервный поиск ограничил сумму целевых уставок, хотя ограничение относится к
фактическому отбору. Такая проекция консервативна и может необязательно снижать
добычу. Потеря 11,12 млн руб. — цена конкретных реализованных изменений плана,
а не доказанная минимальная цена выполнения условий. Для исправления следует
сначала проверять исходный план с обязательными простоями по динамическому
отклику и менять дебиты только при фактическом/прогнозируемом превышении лимита.

Эксперимент после раскрытия результата становится диагностическим материалом.
Его нельзя снова представлять как независимый слепой тест после настройки
алгоритма или модели на этих результатах. Production-веса этим экспериментом
не изменялись.
