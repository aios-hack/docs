# v1 — архив первой версии

Здесь лежит работа, которая **закрыта и не является планом**. Открывать только чтобы понять, почему что-то сделано именно так; действующие решения и текущие задачи — не здесь.

| Что | Состояние |
|---|---|
| `assignments/` | Четыре персональных пакета и сквозной порядок 65 задач. Все закрыты. `order.md` остаётся историческим свидетельством: там записано, каким коммитом закрыта каждая позиция |
| `context/09_tasks.md` | Разбиение на те же 65 задач с приёмкой |
| `context/05_solution_space.md` | Каталог рассмотренных вариантов. Часть помечена как отвергнутая — самая опасная часть архива, если читать её как рекомендацию |

**Чего здесь нет и не будет.** Предметная база знаний осталась в корне репозитория, в `../context/`: контракты данных, принятые решения, разбор дека и Методики, открытые вопросы, требования организаторов. Она общая для любой версии решения и продолжает действовать — переносить её в архив было бы враньём о её статусе.

Текущая работа — в `../v2/`.
