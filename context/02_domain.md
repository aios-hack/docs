## 1. Главный тезис

**Месторождение — единая динамическая система.** Локальное изменение режима одной скважины перераспределяет потоки, меняет поля давления, обводнённость и эффективность всего окружающего фонда [Разр.3].

Отсюда следует и требование к архитектуре: «согласованные решения на уровне объекта, а не локальная оптимизация отдельных скважин» [Разр.26].

Финальный слайд лекции формулирует четыре принципа [Разр.30]:
1. считать объект связной системой — решение по одной скважине оценивается через отклик всего объекта;
2. учитывать физику процесса (Дарси, депрессии, ОФП, неоднородность);
3. соблюдать технологические ограничения;
4. работать на итоговый результат — технологический эффект должен подтверждаться экономическим.

## 2. Базовая физика

**Фильтрационно-ёмкостные свойства (ФЕС)** [Разр.4]: пористость `m`, проницаемость `k`, нефтенасыщенность `Sн`, эффективная толщина `Hэф`.

**Закон Дарси** [Разр.6]: расход `q` растёт с проницаемостью и перепадом давления, падает с вязкостью. Ключевой вывод: **поток идёт преимущественно по зонам с высокой гидропроводностью**. Управление режимами = управление перепадами давления и перераспределением потоков в среде с неоднородной проводимостью.

**Формула Дюпюи** [Разр.7]: дебит жидкости зависит от `k·h` и депрессии `(Pпл − Pзаб)`. Завышенная депрессия ускоряет конусообразование, прорыв воды и выработку наиболее проводящих пропластков.

**ОФП (относительные фазовые проницаемости)** [Разр.8]: по мере роста водонасыщенности меняется способность пласта пропускать нефть и воду. При отношении подвижностей `M > 1` вода опережает нефть, фронт теряет устойчивость — viscous fingering.

**Неоднородность** [Разр.5] — ключевой фактор, определяющий реальную геометрию фронта вытеснения.

## 3. Давления

| Величина | Смысл |
|---|---|
| `Pпл` | пластовое — интегральный индикатор запаса пластовой энергии объекта |
| `Pзаб` | забойное — локальный режим работы конкретной скважины |
| `ΔP = Pпл − Pзаб` | депрессия (для добывающей) / репрессия (для нагнетательной) — она и вызывает движение жидкости |

[Разр.16, 12.08 03:32]

**Почему различие критично:** падение дебита может быть вызвано и снижением `Pпл`, и ростом `Pзаб`, и ухудшением продуктивности — для каждой причины нужно своё решение [Разр.16].

Прямая подсказка для обучения агента: «Нагнетательную скважину можно обучать на забойное давление закачки, можно на пластовое — для этого есть своя чувствительность» [12.08 04:07].

## 4. KPI: читаются по цепочке скважина → пласт → фонд → экономика

[Разр.12]

| Уровень | Показатели |
|---|---|
| Скважина | `Qн`, `Qж`, `Qв`, `WCT`, `Pзаб`, PI/II, ГФ |
| Пласт | `Pпл`, `ΔP`, `Sw`, sweep, связность, **лаг отклика** |
| Фонд | `Kисп`, `Kэксп`, простои, отказы, ПРС/КРС |
| ППД | `Qзак`, `Kкомп`, `Pнаг`, профили приёмистости, отклик |
| Поверхность | headroom по жидкости, воде, газу; ДНС/УПСВ/КНС |
| Результат | `Np`, КИН, unit OPEX, ЧДД / NPV |

**Правило интерпретации: одиночная метрика не диагностична.** Вывод формируется из согласованной динамики режима, давления, состава продукции, закачки и **лага отклика** [Разр.12].

### Формулы

Добывающая скважина [Разр.13]:
- дебит нефти: `Qн = Qж · (1 − WCT)`
- обводнённость: `WCT = Qв / Qж`
- водонефтяной фактор: `ВНФ = Qв / Qн`
- индекс продуктивности: `K = q / (Pпл − Pзаб)` — более устойчивый параметр, чем абсолютный дебит [Разр.7]

Нагнетательная скважина [Разр.14]:
- приёмистость `Qзак` — **сама по себе не определяет эффективность**
- коэффициент приёмистости: `I = Qзак / (Pзаб,наг − Pпл)`
- текущая компенсация: `Kкомп = Qзак / Qотб,прив`
- профиль приёмистости — адресность воздействия
- **отклик добывающих скважин — именно лаг и амплитуда определяют реальную полезность нагнетательной**

Фонд [Разр.15]:
- `Kисп = Nдейств / (Nдейств + Nбезд)`
- `Kэксп = tработы / tкалендарное`

Баланс [Разр.17]:
- приведённый отбор: `Qотб,прив ≈ Qн·Bн + Qв·Bв` (объёмы сопоставляются **в пластовых условиях**, не по поверхностным замерам)
- КИН: `Qнак.н / НИЗ`

## 5. Компенсация — центральное понятие для агента закачки

`Kкомп = Qзак / Qотб,прив`. При `Kкомп < 1` отбор опережает закачку; при `> 1` — возможна локальная перекомпенсация [Разр.15].

Дословно об этом как о целевой функции: «Это как раз целевая, можно сказать, функция мат-баланса для агента, который стремится максимально закачать воду» [12.08 00:46].

**Ключевое предупреждение — типичный провал наивного агента:**
> «Первое, что пытается сделать агент, — это разогнать максимум твою скважину: если это нагнетательная — закачку, добывающую — забойное [давление] минимальное, максимальную закачку. Вот эти вещи чтобы учитывать, сразу реагирует на нужную компенсацию... не является целевой функцией закачать воду» [12.08 01:02, 02:04]

**Почему одного коэффициента недостаточно** [Разр.17]: одинаковое `Kкомп` может соответствовать и эффективному распределению закачки, и технологически неэффективной циркуляции воды по ограниченному контуру. Оценивать совместно с динамикой `Pпл`, обводнённости, профилями приёмистости и откликом добывающего фонда.

При недостаточной компенсации система теряет пластовую энергию; при избыточной — рост давления, неэффективная циркуляция, ускоренное промывание активных каналов. Аномально высокое `Pпл` в перекачанных зонах «экономически только съедает проект» [12.08 03:19].

## 6. Четыре цели системы ППД

[Разр.18, 12.08 04:45] — это, по словам автора, «один общий набор правил и практик, как агент должен управлять закачкой».

1. **Управление фронтом вытеснения без прорывов воды** — равномерный охват пласта. Особенно актуально во втором треке, где разрешён перевод добывающих в нагнетательные: «вы в этот момент начинаете вмешиваться напрямую во фронт вытеснения» [12.08 05:27].
2. **Обеспечение целевой компенсации** — баланс закачки и отбора, равномерно по скважинам и участкам.
3. **Поддержание пластового давления без перекачки отдельных зон** — бывают участки, где компенсация держится на единице, а `Pпл` падает [12.08 06:18].
4. **Разгрузка товарных парков и согласование с инфраструктурой**.

## 7. Методы регулирования заводнения

[Разр.19]
- **ИНФП** (изменение направлений фильтрационных потоков) — перераспределение отбора и закачки для вовлечения слабо дренируемых зон. Самый капиталоёмко-эффективный метод; на практике делается многовариантными расчётами на ГГДМ или гидропрослушиванием [12.08 07:53].
- **Форсированный отбор жидкости** — активизирует слабо дренируемые зоны, но без контроля ускоряет обводнение.
- **Высокие давления нагнетания** — повышают репрессию, но в неоднородной среде усиливают движение воды по предпочтительным каналам.
- **Циклика** — организаторы прямо рекомендуют: «в обоих треках это и нужно делать. Агенты должны понять локально защемлённые зоны и цикликой их вовлечь» [12.08 56:33]. Иногда выгодно циклировать высокообводнённую скважину [12.08 02:49].

Ключевое ограничение: любой метод эффективен только при учёте неоднородности, ОФП, текущей насыщенности и фактической межскважинной связи.

## 8. Причины прорывов воды

[Разр.20]
1. Каналы высокой проводимости — высокопроницаемые пропластки, трещины, заколонные перетоки шунтируют нефтенасыщенный объём.
2. Завышенные градиенты давления — форсированный отбор и жёсткая закачка усиливают селективность.
3. Неблагоприятный mobility ratio (`M > 1`).
4. Избыточная депрессия / конусообразование — низкое `Pзаб` подтягивает подошвенную воду. В модели Z есть аквифер: «когда мы начинаем резко форсировать отбор жидкости, при этом нагнетательные скважины могут стоять далеко, но мы начинаем подтягивать конус воды снизу» [12.08 10:53].

## 9. Диагностические паттерны для агента

[Разр.21, 12.08 20:02] — это фактически готовый список признаков/правил для диагностического слоя.

| Наблюдение | Интерпретация |
|---|---|
| Изменение закачки → отклик добычи **с лагом** | лаг зависит от расстояния, ФЕС и связности |
| Рост `WCT` без роста `Qн` | прорыв воды, перекачка активного канала, или смещение фронта в выработанную зону |
| Резкий рост жидкости при неизменной нефти + рост воды | воду откуда-то подтянули: соседняя нагнетательная или конус снизу [12.08 21:20] |
| Падение `Pпл` при внешне высоких дебитах | риск потери пластовой энергии, нестойкий режим |
| Высокая закачка без полезного отклика | локальная циркуляция, нецелевая закачка, отсутствие связи с приоритетным добывающим фондом |
| Рост `Qн` без роста `Qж` | поймали невыработанную / защемлённую зону — агенту стоит запомнить направление фронта [12.08 46:31] |

**Про обучение на лаге, дословно:**
> «Подкрепляться нужно не просто фактом, который он получил после какого-то воздействия. Подкрепляться нужно добычей... закачку ввели, у нас отложенный лаг возникает по добыче... И вот в этом случае мы должны обучаться именно на этот лаг» [12.08 20:26]

**Про ВНФ как диагностический KPI:**
> «ВНФ больше подсвечивает как параметр для обучения агентов, как диагностический KPI, который агент понимает: как этот ВНФ меняется, от чего он меняется, какие параметры на него влияют... "максимальная жидкость — значит максимальная нефть" — как бы не всегда. Когда вы это агенту объясните, отчего это зависит, на ВНФ гораздо легче будет управлять системой» [12.08 51:36]

## 10. Связи между скважинами

Три типа парных связей, которые агент должен научиться чувствовать [12.08 27:01]:
- закачка → добыча
- добыча → добыча
- закачка → закачка

**Пространственная близость ≠ гидродинамическая связь.** «Насколько близко пространственное расстояние — оно не означает, что у них есть гидродинамическая связь. Этим вещам агента тоже нужно обучать» [12.08 27:13].

При этом для модели Z: «сетка более выдержанная, это очень удобно для обучения агентов, но обратно взвешенное расстояние как граф-признак учитывать всё равно придётся, потому что есть такие зоны... и через расстояние калиброваться модель тоже придётся» [12.08 34:52].

> Прямая подсказка в сторону графовых признаков / GNN — расстояние как приор, но связность обучаемая.

## 11. Экономика

Целевая функция: `max ЧДД (NPV)` [Разр.29].

**Технологический смысл:** «Разрешено временно ухудшить часть локальных параметров, если это повышает накопленную добычу нефти и экономическую ценность объекта на горизонте расчёта» [Разр.29].

**Вода штрафуется дважды:**
> «Штрафуется вода, то есть лишняя вода, которая идёт в потоке жидкости, потому что норматив на жидкость идёт и норматив на закачку. То есть потратили деньги, чтобы добыть, потратили деньги, чтобы закачать. Соответственно, эти затраты двойные мы должны окупить на ближайшем окружении скважин как минимум с каким-то коэффициентом 1:1 по ЧДД» [12.08 42:57]

**OPEX состоит из двух частей** [12.08 50:24]:
- постоянная — считается независимо от мероприятий, идёт на жидкость, на закачку и на количество скважин;
- переменная — зависит от мероприятий, например смена насоса (включая стоимость выезда бригады).

Стоимость смены насоса и параметры ЭЦН по типам/размерам уже заложены в предоставляемый калькулятор экономики [12.08 49:28].

**Инструмент.** Обещанная 12.08 платформа расчёта экономики по скважинам [12.08 38:27] материализовалась 13.08 как `CHDD_PYTHON.zip` — эталонный расчётчик на Python, считающий «по той же методике, что применяется при оценке», с нормативами, макетом входа, примерами вывода в Excel и JSON, README и автотестами [канал, сообщение 35]. Действующая методика — `Методика_расчета_ЧДД_скорректированная.docx`, она заменяет прежнюю редакцию. Разбор — `06_open_questions.md` §2б.

Практическая подсказка от автора: принцип Парето — 20% скважин дают 80% результата, работать нужно адресно с «зелёными» скважинами [12.08 39:46].

**Ограничения по реализации тоже часть критерия рационального решения** [Разр.29]: воспроизводимость, прозрачность логики, возможность запуска и проверки в регламентированной среде.

## 12. Свойства модели Z (трек 2)

[12.08 33:33]
- модель взята **с реального месторождения**, но геология сильно перестроена — полусинтетика;
- **сетка скважин реальная**, режимы работы скважин синтетические [12.08 45:46];
- **2 пласта с выклиниванием**, сильно пересекаются;
- **109 скважин** — так говорит лекция; **по деку их 103**, разбор расхождения в `04_models.md` §2;
- неоднородное распределение запасов — связано не столько с геологией (она выдержана по пористости/проницаемости), сколько с историей режимов эксплуатации;
- есть **аквифер**: не на постоянном давлении, у него собственный мат-баланс и ограниченная поровая ёмкость; активно питает первые ~5–7 лет; может и принять, и отдать [12.08 56:44];
- на добывающем фонде ГРП делали по истории, дальше не делают, продуктивность по нему не падает [12.08 54:22];
- один прогон ~15 минут [12.08 35:18].

Стадия разработки: тестовое задание задаётся на уровне **третьей стадии** — всё уже введено в эксплуатацию [12.08 07:24]. По классификации [Разр.10] это «падение и перераспределение»: рост WCT, выбывание фонда, локализация остаточных запасов, повышение адресности ППД.

Типовая ситуация из кейса [12.08 35:27]: нужно сменить насос на добывающей скважине → остановить закачку по соседним → добычу терять нельзя → нужно перераспределить закачку. «В реальной жизни посчитать очень сложно, потому что это многовариантный расчёт и постоянно условия задачи могут меняться.»

## 13. Целевое видение системы (то, что хочет заказчик)

[Разр.23] Цифровая система должна работать как контур принятия решений: **мониторинг → анализ → прогноз → оптимизация → контроль результата**, и уметь:

1. интегрировать данные по фонду, ППД, давлениям, добыче, закачке, исследованиям и поверхностным ограничениям;
2. **оценивать межскважинные связи и лаги отклика** — выявлять реально влияющие пары нагнетательная-добывающая;
3. диагностировать проблемы: прорывы воды, неравномерный фронт, перекомпенсацию, неэффективную закачку, выпадение фонда;
4. прогнозировать результат управляющих действий на основе ГГДМ или качественной суррогатной модели;
5. формировать согласованные решения по фонду и **ранжировать их по технологическому и экономическому эффекту**.

**Ключевой принцип:** «Цифровая система должна усиливать инженерную интерпретацию и обеспечивать воспроизводимое принятие решений, а не подменять физику процесса формальным подбором режимов» [Разр.23].

Два компонента названы важнейшими [12.08 25:27]:
- качественная оценка межскважинных связей,
- корректный прогнозируемый отклик на управляющие действия.

## 14. Замечание про данные

В реальности таких чистых данных не бывает: ГДИ, трассерные исследования, гидропрослушивание проводятся не на всех скважинах, межскважинное пространство остаётся «загадкой», есть систематические и случайные шумы замеров [12.08 22:29, 23:06].

Мы работаем с идеальным случаем. Отсюда требование: **агент должен понимать физику, а не запоминать данные**, иначе он не перенесётся ни на тестовый кейс, ни в производство [12.08 23:38].
